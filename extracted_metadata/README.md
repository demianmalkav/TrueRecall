# Extracted Metadata

Only non-copyrightable/research metadata derived from the user's verified ROM belongs here: offsets, sizes, hashes, dimensions, resource descriptors, symbol maps and normalized structural observations.

Do not commit extracted sprites, tile dumps, maps rendered from copyrighted art, music, PCM samples or large raw binary blocks.

Machine-readable indexes created by the tools should be reproducible from the canonical base ROM and document the tool/version that generated them.
