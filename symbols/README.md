# Symbols

Stable reverse-engineering symbols and label maps belong here.

Rules:

- Symbol names must reflect proven semantics or carry a provisional prefix.
- Preserve original Beam names when recovered from retail diagnostics or other direct evidence.
- Do not rename an unresolved field/function merely to make code look clean.
- Every stable symbol should be traceable to `docs/ROM_MAP.md`, `docs/RAM_MAP.md`, a probe, or runtime evidence.

Future outputs may include assembler symbol files, debugger labels and machine-readable address maps.
